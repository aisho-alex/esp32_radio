# FM Radio Controller (ESP32 / ESP32-C3 / ESP8266)

Веб-управляемый FM-приёмник на модуле **RDA5807M** с дисплеем 1602/2004, часами реального времени и энкодером. Одна кодовая база для трёх платформ, сборка через **PlatformIO**.

## Возможности

- **Веб-интерфейс** — современный UI в ретро-стиле, адаптирован под мобильные
- **Ручная настройка** — ползунок и кнопки точной настройки (0.1 МГц)
- **Seek и сканирование** — автопоиск станций по диапазону
- **Пресеты** — до 20 станций в EEPROM (формат совместим с ESP8266-версией)
- **Громкость** — 16 уровней, mute, RSSI и индикатор стерео в UI
- **Символьный LCD** 16×2 / 20×4 (PCF8574 I2C) — частота, стерео, громкость, RSSI, часы
- **RTC** DS3231 (или DS1307) — время на дисплее, установка через API из браузера
- **Энкодер KY-040** — громкость / частота / seek / mute без телефона
- **mDNS** — интерфейс доступен по адресу `http://fm-radio.local`
- **OTA-обновление** — прошивка по HTTP без подключения по USB
- **39 юнит-тестов** (Unity) — логика покрыта и гоняется на хосте без железа

## Схема подключения

Все I2C-модули подключаются **параллельно** к одной шине (SDA/SCL и питание).

```text
 MCU (ESP32 / ESP32-C3 / ESP8266)
 ┌──────────────┐        3.3V ────┬──────────┬──────────┬──────────┐
 │   3V3 ───────┼──────────────> VCC      VCC      VCC      (+)   │
 │   GND ───────┼──────────────> GND      GND      GND      GND   │
 │              │                 │        │        │        │     │
 │   SDA ───────┼───┬─────────> SDA      SDA      SDA      │     │
 │   SCL ───────┼─┬─┼─────────> SCL      SCL      SCL      │     │
 └──────────────┘ │ │                                      │     │
                  │ │   RDA5807M   LCD1602 (PCF8574)  DS3231 │     │
                  │ │   (FM-модуль) (дисплей)        (RTC)   │     │
                  │ │                                        │     │
                  │ └────────────────────────────────────────┘     │
                  └──────────────────> на энкодер: A/B/SW (ниже)   │
```

**Важно:** все модули питаются от **3.3V**! Не подключайте к 5V. К выводу **ANT** модуля RDA5807M — провод 20–75 см в качестве антенны.

### Распиновка по платам

| Сигнал | ESP32 DevKit (WROOM-32) | ESP32-C3 DevKitM-1 | ESP8266 NodeMCU |
|---|---|---|---|
| I2C SDA | GPIO21 | GPIO8 | D1 (GPIO5) |
| I2C_SCL | GPIO22 | GPIO9 | D2 (GPIO4) |
| Энкодер A (CLK) | GPIO32 | GPIO4 | D5 (GPIO14) |
| Энкодер B (DT) | GPIO33 | GPIO5 | D6 (GPIO12) |
| Энкодер SW | GPIO25 | GPIO6 | D7 (GPIO13) |

### Модули

| Модуль | Адрес I2C | Заметки |
|---|---|---|
| RDA5807M | 0x10 / 0x11 | FM 87.5–108 МГц, выход на наушники/усилитель |
| LCD 1602/2004 (PCF8574) | 0x27 или 0x3F | определяется автоматически |
| RTC DS3231 | 0x68 | DS1307 — включается флагом `-DUSE_DS1307` |
| Энкодер KY-040 | — | не I2C: A/B/SW → GPIO из таблицы выше |

Если энкодер крутится «в обратную сторону» — поменяйте местами `-DENC_A` и `-DENC_B`.

## Энкодер

| Жест | Действие |
|---|---|
| Вращение | Громкость ±1 |
| Вращение при удержании кнопки | Частота ±0.1 МГц |
| Короткое нажатие | Seek следующей станции |
| Длинное нажатие (≥0.6 с) | Mute вкл/выкл |

## Дисплей

```text
┌────────────────┐
│ FM 101.50 MHz ST│   частота + индикатор стерео
│ V08 R24 12:34  │   mute(М)/громкость, RSSI, часы из RTC
└────────────────┘
```

Обновление раз в секунду, без блокировки; перерисовываются только изменившиеся строки.

## Сборка и прошивка

1. Установите [PlatformIO](https://platformio.org/) (расширение VS Code или CLI)
2. В корне проекта:

```bash
pio run -e esp32dev -t upload    # ESP32 DevKit
pio run -e esp32-c3  -t upload   # ESP32-C3
pio run -e nodemcuv2 -t upload   # ESP8266 NodeMCU
pio run                          # собрать всё без прошивки
```

Через VS Code: панель **PlatformIO → Project Tasks → <окружение> → Upload**.

С версии VS Code CLI может отсутствовать в PATH — тогда используйте `~/.platformio/penv/bin/pio`.

### Конфигурация (build_flags в platformio.ini)

| Флаг | По умолчанию | Описание |
|---|---|---|
| `WIFI_AP_MODE` | `true` | `false` — режим клиента (STA) |
| `WIFI_SSID` / `WIFI_PASSWORD` | — | данные сети для STA-режима |
| `AP_SSID` / `AP_PASSWORD` | `FM-Radio` / `12345678` | точка доступа |
| `I2C_SDA` / `I2C_SCL` | по плате | пины шины I2C |
| `ENC_A` / `ENC_B` / `ENC_SW` | по плате | пины энкодера |
| `LCD_COLS` / `LCD_ROWS` | 16 / 2 | геометрия дисплея (попробуйте 20/4) |
| `LCD_I2C_ADDR` | авто (0x27/0x3F) | зафиксировать адрес LCD |
| `USE_DS1307` | выкл. | использовать DS1307 вместо DS3231 |

### Режимы WiFi

**AP (по умолчанию):** сеть `FM-Radio`, пароль `12345678`, адрес `192.168.4.1`.
**STA:** задайте `WIFI_SSID` / `WIFI_PASSWORD` и выставьте `WIFI_AP_MODE false`.

## Использование

1. Откройте Serial Monitor (115200) — там IP, статус модулей и адрес OTA
2. Подключитесь к WiFi и откройте адрес устройства (или `http://fm-radio.local`)
3. Управляйте радио из браузера, энкодером или с дисплея

### API

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/` | Веб-интерфейс |
| GET | `/api/status` | Частота, громкость, mute, стерео, RSSI |
| POST | `/api/tune` | Частота `{frequency: 10150}` (в единицах 100 кГц) |
| POST | `/api/seek` | Поиск `{direction: "up" \| "down"}` |
| POST | `/api/volume` | Громкость `{volume: 0-15}` |
| POST | `/api/mute` | Звук `{muted: true \| false}` |
| GET | `/api/scan` | Сканирование диапазона |
| GET/POST | `/api/presets` | Список / добавление пресетов |
| DELETE | `/api/presets/{index}` | Удаление пресета |
| GET | `/api/time` | Время из RTC `{available, epoch, datetime}` |
| POST | `/api/time` | Установка времени `{epoch: <unix>}` (2001–2100) |

### OTA

Веб-обновление: `http://<ip>/update` (логин/пароль: `admin` / `admin`).

## Тесты

Логика (пресеты, валидация частоты, JSON-контракты API, форматирование LCD, жесты энкодера) вынесена в `include/radio_logic.h` и покрыта тестами:

```bash
pio test -e native                    # на хосте, без железа
pio test -e esp32dev                  # на устройстве (прошьёт и прогонит)
```
